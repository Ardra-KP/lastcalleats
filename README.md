# Last Call Eats 🍔
A complete Food Ordering Platform built with Django & Django REST Framework

## ✨ Features
- User Registration & JWT Authentication
- Restaurant & Menu Browsing  
- Add to Cart & Place Order
- Admin Dashboard for Order Management
- PostgreSQL Database + PythonAnywhere Deployment

## 🛠️ Tech Stack
`Python` `Django` `Django REST Framework` `PostgreSQL` `Bootstrap 5` `JWT`
